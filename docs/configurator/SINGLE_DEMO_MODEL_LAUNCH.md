# Single Demo Model Launch Boundary

Auto AI India will temporarily ship one clearly labeled configurator demonstrator while the full OEM catalog and licensed 3D asset program remains deferred.

## Rules

- The demonstrator is a visual/demo experience, not a claim of verified OEM production catalog readiness.
- Production `autoai` collections remain authoritative for real vehicle variants and must not be populated with synthetic OEM data.
- The demonstrator must not bypass backend pricing, compatibility, validation, or publication rules for real catalog records.
- Future licensed/verified GLB assets can replace the demonstrator without changing the Configurator UI contract.

## UX

The Configurator should show:
- a premium 3D vehicle scene;
- orbit/zoom/camera controls;
- paint presentation;
- wheel/interior presentation where supported by the actual asset;
- cinematic showroom mode;
- responsive desktop/mobile layout;
- clear `Concept / Demo Model` labeling.

The old flat-image showroom must not be presented as a 3D model.
